## Structure

```
/chapters   — Figures organized by chapter
/source     — Editable source files (.svg, .drawio, etc.)
/export     — High-res exports (.png, .pdf)
```
## Formatting

- Helvetica Font
- Clear Labeling
- First Letter Capitalization for In-Figure Labels
- Title Case for Figure Labels (Captions)
